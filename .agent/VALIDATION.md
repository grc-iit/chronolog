# Phase 0 Validation Notes

This file is intentionally minimal at setup time.

For Phase 0 work, each completed task must record:

- command or workflow executed
- exit status
- result directory under `.agent/results/`
- relevant stdout/stderr/log files
- whether Kafka and Mofka source trees remained unchanged
- commit hash for validated milestones

Do not mark a task complete in `.agent/TASKS.md` unless the validation evidence exists.
